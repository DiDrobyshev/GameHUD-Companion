## 🗲 О проекте

**GameHUD Tactical Companion** спроектирован специально для игр на одном мониторе. Интерфейс выполнен в контрастной матовой черно-желтой гамме (Industrial / Cyberpunk HUD), не перегружает зрение и не отвлекает от игры.

Вместо медленного переключения окон по `Alt + Tab`, тяжелых вкладок браузера и громоздких программ вы получаете единый прозрачный центр управления прямо поверх экрана игры.

## 🚀 Ключевые модули

### 📝 1. Минималистичный Блокнот (Clean Markdown HUD)
* **Никаких сплит-экранов:** только одно чистое, контрастное поле для записей без некликабельных окон предварительного просмотра.
* **Вкладки и профили:** быстрое переключение между играми и гайдами (заметки изолированы и не перезаписывают друг друга).
* **Автосохранение:** все изменения автоматически сохраняются на диск в папку `data/notes/` в открытом формате `.md`.
* **Интерактивные чекбоксы:** трекинг дейликов и фарма (`- [ ]`) с визуальным прогресс-баром и сбросом в один клик.

### ⚡ 2. Нижняя Док-панель: AI Copilot с веб-поиском
* **Универсальное подключение:** поддержка бесплатных ключей **Gemini 2.5 Flash** (через Google AI Studio), **OpenRouter** или любого стороннего OpenAI-совместимого эндпоинта.
* **🌐 Web Search (Поиск по вики и форумам):** при активном тумблере ИИ-ассистент в реальном времени ищет актуальную информацию по базам данных, Fandom, Reddit и игровым вики.
* **Кнопка `[📝 В заметку]`:** перенос любого ответа нейросети или переведенного фрагмента в конец открытой заметки в один клик.
* **Компактная консоль:** строка ввода высотой всего 42px с разворачиваемой по требованию историей диалога.

### 🌐 3. Экранный OCR-переводчик под курсором
* **Захват под курсором (`G1` / Хоткей):** считывание подсказок и характеристик предметов без кликов мышью — игра не теряет фокус, а тултипы не исчезают.
* **Автономная связка:** нативный движок `Windows OCR` распознает текст за 10–20 мс, а открытый шлюз Google Translate переводит его без обязательных API-ключей.
* **Режим «Стоп-кадр» (`Alt + T`):** заморозка экрана для комфортного выделения длинных диалогов или квестов рамкой.

### 🎬 4. Ghost PiP Видеоплеер с плейлистом
* **Поддержка платформ:** воспроизведение YouTube, Twitch, VK Видео и локальных видеофайлов.
* **Очередь воспроизведения (Playlist / Queue):** добавление нескольких ссылок или плейлиста с последовательным автопереходом к следующей серии/ролику.
* **Ghost Mode (`Alt + L`):** включение нативного режима сквозного клика (`click-through`). Окно видео становится полностью неосязаемым для курсора мыши — можно целиться и стрелять прямо сквозь него.
* **Boss Key (`Alt + H`):** экстренное сворачивание плеера с мгновенным глушением звука на время катсцен или напряженных боев.

### ⏱ 5. Плавающий HUD Таймеров
* Автономный микро-виджет с отображением активных таймеров (боссы, ресурсы, баффы).
* Свободное перетаскивание мышкой в удобную зону экрана.
* Быстрый запуск по хоткеям и звуковое оповещение по окончании отсчета.

## ⌨ Горячие клавиши (по умолчанию)

> Любую комбинацию можно переназначить в настройках под клавиатуру или макрос-кнопки мыши (`G1`–`G5`).

| Хоткей | Действие | Описание |
|---|---|---|
| `G1` / `Alt + X` | **Показать / Скрыть оверлей** | Мгновенный вызов главного окна поверх игры |
| `Alt + G` | **Ghost Mode (Блокнот)** | Сквозной клик сквозь открытые заметки |
| `G2` / `Alt + W` | **Перевод под курсором** | Быстрый захват и перевод тултипа под мышкой |
| `Alt + T` | **Стоп-кадр и выделение** | Заморозка экрана для обводки произвольной области |
| `Alt + 5` | **Быстрый таймер (5 мин)** | Создание таймера на панели HUD |
| `Alt + L` | **Ghost Mode (PiP-видео)** | Блокировка окна плеера от случайных кликов |
| `Alt + P` | **Пауза / Плей видео** | Управление видеорядом без потери фокуса игры |
| `Alt + H` | **Boss Key (PiP)** | Скрыть видео и заглушить звук |

## 🔑 Настройка AI-ассистента

Для работы умного ассистента в нижнем доке:

1. Перейдите во вкладку **Настройки (⚙)** в правом верхнем углу.
2. Выберите провайдера:
   * **Gemini 2.5 Flash (Рекомендуется):** получите бесплатный API-ключ в [Google AI Studio](https://aistudio.google.com/). Позволяет бесплатно использовать функции поиска в сети (**Web Search / Grounding**).
   * **OpenRouter:** вставьте API-ключ с [openrouter.ai](https://openrouter.ai/) и укажите желаемую модель (например, `google/gemini-2.5-flash` или `meta-llama/llama-3.3-70b-instruct:free`).
3. Включите тумблер `[🌐 Web Search]` в нижней панели ввода, чтобы модель искала актуальные данные по играм в реальном времени.

## 🏗 Архитектура проекта

Приложение построено на мульти-оконной модели **Tauri v2** с нативными системными вызовами WinAPI:

```text
game-notes-overlay/
├── src-tauri/ (Rust Core)
│   ├── src/
│   │   ├── main.rs / lib.rs   # Захват экрана, Windows OCR, drag окон, ghost-mode
│   │   └── commands/          # Системные команды Tauri
│   ├── Cargo.toml             # Зависимости Windows API, xcap, токены
│   └── tauri.conf.json        # Конфигурация мульти-окон (main, timer-hud, pip-hud, snipper)
│
├── src/ (React + TypeScript)
│   ├── components/
│   │   ├── notes/             # Чистый Markdown редактор и менеджер вкладок
│   │   ├── ai/                # Нижняя док-панель, чат и интеграция Web Search
│   │   ├── pip/               # Ghost-плеер с плейлистом и очередью
│   │   ├── timer/             # Виджет плавающего HUD таймеров
│   │   └── translator/        # Всплывающая карточка перевода под курсором
│   ├── store/
│   │   └── useAppStore.ts     # Централизованное состояние Zustand
│   ├── services/
│   │   └── aiService.ts       # Клиент Gemini API и OpenRouter с веб-поиском
│   └── App.tsx                # Главный контейнер в черно-желтой теме
│
└── data/                      # Локальные пользовательские данные
    ├── config.json            # Сохраненные хоткеи, API-ключи, прозрачность
    └── notes/                 # Заметки и гайды (*.md)

## 🚀 Установка и запуск

### Требования
* **ОС:** Windows 10 / 11 (64-bit)
* **Компоненты:** 
  * [Visual Studio C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/)
  * [Rust](https://rustup.rs/)
  * [Node.js (LTS)](https://nodejs.org/)

### Сборка из исходников

1. **Клонируйте репозиторий:**
   ```powershell
   git clone [https://github.com/your-username/game-notes-overlay.git](https://github.com/your-username/game-notes-overlay.git)
   cd game-notes-overlay
   ```

2. **Установите зависимости:**
   ```powershell
   npm install
   ```

3. **Запустите в режиме разработки:**
   ```powershell
   npm run tauri dev
   ```

4. **Соберите релизный `.exe`:**
   ```powershell
   npm run tauri build
   ```
   *Готовый портативный исполняемый файл появится в папке `src-tauri/target/release/`.*

## 🔒 Приватность и Безопасность

* Приложение не собирает телеметрию и персональные данные.
* Экранный OCR выполняется **локально** на вашем процессоре через средства Windows.
* Ваши заметки и изображения хранятся исключительно на вашем диске в папке `data/`.
